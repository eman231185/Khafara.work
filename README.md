# لوحة المدرسة — نسخة كاملة أولية

هذه نسخة Web App عربية RTL مستوحاة من الواجهة الموجودة في تسجيل الشاشة الذي تم تزويده في المحادثة.

## ما الذي يعمل؟
- Dashboard
- إدارة الواجبات: إضافة/تعديل/حذف + بحث وفلاتر
- التقويم وربط الواجبات بمواعيدها
- التوزيع
- التقارير والإحصاءات
- الحضور والغياب مع حفظ حسب التاريخ
- الإعدادات
- Responsive للموبايل والكمبيوتر
- حفظ البيانات محليًا عبر localStorage

## التشغيل
يمكن فتح `index.html` مباشرة في المتصفح.

## نشره على Vercel
ارفع المجلد إلى GitHub ثم اربطه بمشروع Vercel، أو استخدم Vercel CLI من داخل المجلد:

```bash
vercel
vercel --prod
```

## نسخة الإنتاج الحقيقية
للحسابات المتعددة، تسجيل الدخول، مزامنة البيانات بين الأجهزة، صلاحيات المعلم/الإدارة، ورفع الملفات، يجب استبدال localStorage بقاعدة بيانات وخدمة مصادقة وAPI.
